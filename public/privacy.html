Privacy Policy

Gravipress is a static, browser-based compression utility designed to process files locally on your device.

1. Local File Processing

All PDF, image, batch, ZIP, and GZIP operations run directly inside your browser using client-side JavaScript, HTML5 Canvas, and Web Workers. The Gravipress application does not intentionally upload, transmit, or store your selected files on any remote compression server.

2. Analytics, Cookies, and Browser Storage

Based on the Gravipress v1.0 codebase:

  • No analytics or tracking: Gravipress does not load third-party analytics, advertising, or telemetry scripts.
  • No cookies: Gravipress does not set HTTP cookies or document.cookie values.
  • No persistent user document storage: Selected files, filenames, and compressed outputs are never written to localStorage, IndexedDB, or Cache Storage. Files are held in browser memory and temporary blob: URLs, which are released when you reset the workspace or leave the page.
  • Application asset caching (Offline Mode): A native Service Worker may store static application assets (HTML, CSS, JavaScript, and PDF.js resources) in browser Cache Storage so the app can load offline. You can clear optional offline assets at any time using Remove Offline Data.
  • Strict Content Security Policy: Response headers restrict connect-src to 'self', blob:, and data:.

3. Static Hosting & Infrastructure Logs

Gravipress is delivered as a static website on Cloudflare Pages. When your browser requests the application's HTML, CSS, JavaScript, or icon assets over HTTPS, Cloudflare's network infrastructure may process and log standard HTTP request metadata (such as IP address, user-agent, requested URL, and timestamp) for security, routing, and DDoS protection.

For details on how Cloudflare handles infrastructure data, review the Cloudflare Privacy Policy.

4. Public Issue Reports

If you report a bug on GitHub Issues, any text or attachments you submit become public. Do not attach confidential files or personal information to public issues.
